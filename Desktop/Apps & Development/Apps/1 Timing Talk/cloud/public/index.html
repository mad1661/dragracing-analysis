How It Works

1. Track Installs a Pi

Each track gets a small Raspberry Pi connected to their timing system. It reads serial data and streams it to the cloud. Plug in, name the track, connect to WiFi -- done.

2. Data Hits the Cloud

Timing data streams to Firebase in real-time. If the internet drops, data is logged locally and synced when it comes back. Nothing is ever lost.

3. You Build With It

Use our API, SDK, or online apps to show live timing on your website, build a scoreboard, create a mobile app, or anything else you can imagine.

Already Use Serial Software?

If you have existing software that reads from a COM port, our legacy desktop app creates a virtual serial port on your computer and streams cloud data to it. Your software works exactly as before -- no changes needed.
