Note: Most users should use the API or online apps instead. The desktop app is for legacy software that requires a physical COM/serial port.

How It Works

1. Install & Sign In

Download and run the app. Sign in with the same account you use on this website.

2. Pick a Track

Browse the live track directory and select the track you want data from.

3. Start the Bridge

The app creates a virtual COM port. Point your existing timing software at it and you're live.

Setup Guide

Windows

  1. Download and run TimingTalk-Setup.exe
  2. If Windows SmartScreen appears, click "More Info" then "Run Anyway"
  3. The app installs and creates a desktop shortcut
  4. Sign in, select a track, click "Start Bridge"
  5. A virtual COM port (e.g. COM10) appears in Device Manager
  6. Point your timing software to that COM port

macOS

  1. Download and open TimingTalk.dmg
  2. Drag the app to your Applications folder
  3. Important — before first launch: Open Terminal and run:
    xattr -cr /Applications/Timing\ Talk.app
  4. Now double-click to open, or right-click → Open if prompted
  5. Sign in, select a track, click "Start Bridge"
  6. A virtual serial port appears at /dev/pts/...
  7. Point your timing software to that path

Linux

  1. Download the AppImage
  2. Make it executable: chmod +x TimingTalk.AppImage
  3. Run: ./TimingTalk.AppImage
  4. Sign in, select a track, click "Start Bridge"
  5. Virtual serial port created via socat

Troubleshooting

IssueSolution
App won't startMake sure you're on a supported OS version. Try running as administrator.
Can't see virtual COM portWindows: install com0com. Mac/Linux: install socat.
No data streamingCheck that the selected track is online (green badge on track list).
Connection dropsThe app auto-reconnects. Check your internet connection.
"Track not found"The Pi at that track may be offline. Try refreshing the track list.

Don't need a COM port? Use the API directly instead.
