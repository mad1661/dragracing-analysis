Quick Start

Add this to any webpage to start streaming live timing data:

<script src="https://nhra-timing-api.web.app/timing-talk.js"></script>
<script>
  const tt = new TimingTalk("YOUR_API_KEY");
  tt.stream("DEVICE_ID", (data) => {
    console.log(data.raw);
  });
</script>
